# 设计语言

> **暖纸落墨（Warm paper, drawn in ink）。** 整套调色板由一种暖近黑墨
> （`#26251e`）按分级比例混入一种暖米白纸（`#f7f7f4`）构成，再加一种暖橙强调色
> （`#eb5600`），且只用于状态——链接、激活、焦点。
> **动作用墨；强调色只表状态。**

jojo 是一套由 **perelmangao** 创作的、框架无关的原创设计系统，以作者的猫
jojo 命名。它独立运作，与任何公司或产品无关联，并以 MIT 许可证发布。本页是设计语言
本身的参考——这些规则正是 [tokens](../../tokens/)、组件基础组件以及
[规格卡片](../../guidelines/) 共同编码的内容。接入的项目只需链接一个文件——
[`styles.css`](../../styles.css)——并从 `window.JojoDesignSystem` 读取组件。

## 机制即系统

整套中性色阶就是一种墨分级混入一种纸。边框是墨加透明度；弱化文本是墨加透明度；
卡片色阶是纸朝墨分级。复刻这套机制，你就复刻了 jojo。**五大标志：**

1. **暖纸单色，机制上只有一种色相。** 米白加暖近黑墨；每个中性色都是墨分级混入纸。
   偏橄榄暖调，绝不偏蓝灰。
2. **锐利的 4px 卡片与全圆角胶囊控件。** 近方形容器，按钮、标签、圆点完全圆角。
   不用 8–16px 的柔角卡片。
3. **硬朗的近黑 1px 卡片描边**——一道纯墨制图笔触，用于带框卡片、强调卡片与 CTA 边缘，
   与几乎不可见的细描边并置，用于辅助型界面外框。两种边框的反差正是那处精致的标志。
4. **大号、轻量的怪诞体（grotesque）大字。** 36–72px，字重 **400**，带强烈的负字距。
   粗体（700）很罕见。再加 EB Garamond 衬线体用于真正的引导正文。
5. **扁平、哑光，一种克制的强调色。** 阴影一律为装饰性的零；纵深来自暖卡片色阶。
   橙色只用于链接、激活与焦点文本——绝不作为填充。

## 内容基础——jojo 如何书写

声音是具体、笃定、不浮夸的。它尊重你的时间，从不过度推销。

- **人称与称呼。** 第二人称，直接——“你”“你的界面”。系统是能力陈述的主语
  （“一个令牌解析为当前主题”）；你是结果的主语（“你顺着纹理设计，而非逆着它”）。
- **句子形态。** 短促、陈述、动词在前。一行一个意思。标题是单个名词短语或一句
  3–6 个词的主张；正文用一两句平实的话展开。避免分号与层层嵌套的从句。
- **大小写。** 几乎处处用句首大写（sentence case）——标题、按钮、导航、标签。
  标题式大写（Title Case）罕见且仅作保留用途（专有名词、文字标）。绝不用全大写来强调；
  强调来自字号与橙色，而非高声。小号等宽体的眉标题与标签可用小写。
- **语气用词。** “calm（沉静）”“legible（清晰）”“disciplined（克制）”
  “consistent（一致）”“warm（温暖）”“flat（扁平）”“token（令牌）”
  “resolved（解析）”——描述机制，而非形容词式的炒作。避免“revolutionary（革命性）”
  “magical（神奇）”“unleash（释放）”“supercharge（增压）”。具体胜过最高级。
- **数字与细节。** 优先用具体细节（令牌名、像 `⌘K` 这样真实的快捷键、精确的 px），
  而非空泛的主张。任何字面量都用等宽体——令牌名、命令、文件路径、快捷键、版本号。
- **动作用动词。** 按钮是动词或名词：“Get started”“Read the docs”“Talk to sales”
  “Become a sponsor”。带尾箭头的 CTA（“Read the docs →”）是文案唯一承载橙色之处。
- **不用表情符号**于产品或营销界面。UI 中不用感叹号。不用表情符号作为项目符号或状态——
  状态用圆点或淡淡的令牌色调（见“图标”）。
- **声音的密度。** 营销留白宽松而安静（一句主张，大量留白）。产品 UI 精简而密集
  （标签，而非整句）。文档可用衬线体并写得更长，但仍保持平实。

*符合此声音的示例：* 一段 hero——**“Warm paper, drawn in ink.”** /
副文案：“jojo is an original, framework-agnostic design system — one warm ink, one
warm paper, one disciplined accent.” 一段功能眉标题——`one ink · one paper` /
**“Familiar, but disciplined.”** 一行 CTA——**Get started**（墨）·
**Read the docs →**（橙）。

## 视觉基础

**颜色。** 一种暖米白纸（`#f7f7f4`，色相约 50–60）加一种暖近黑墨
（`#26251e`）。每个中性色——文本梯级、所有边框、卡片色阶——都是那种墨按分级混入那种纸；
绝不另行挑选独立的灰色。一种暖橙强调色（`#eb5600`）是界面外框中唯一的彩色，
且*只*出现为链接文本、激活态导航的下划线与文本，以及焦点环——绝不作为填充、背景或装饰。
状态色相（ok-green、info-blue、crimson、amber）被限定在内容与数据可视化中，
作为约 12% 的淡色调，配以实色前景；界面外框保持单色。两种主题都是暖的
（浅色色相约 50–60；深色暖黑色相约 48，锚定于 `#100f0a`）——绝不用冷蓝灰的深色。
图像偏暖、中性、哑光、低对比——不用冷调或过饱和的摄影。

**字体。** 大而轻。Display 72px / H1 36px，字重 **400**，带强烈负字距
（−2.16 至 −0.72px），`line-height: 1`。层级来自字号与字距，而非字重——系统以 400 运行，
某些标题升到 500，700 很罕见（仅用于中等字号的小节标题）。怪诞体无衬线（**Geist**）
用于所有 UI 与标题；等宽体（**Geist Mono**）用于**所有**代码、行内代码、命令与搜索输入框、
安装码片与版本号；衬线体（**EB Garamond**）仅用于真正的长篇引导段落与引文。
绝不在单个控件内混用字族。正文 14px / line-height 1.5；阅读行宽约 65–75ch。

**间距与密度。** 精简密集。间距尺度为 2/4/6/8/10/14/20/28px；留白只出现在区块边界
（20–28px），区块内部为 8–10px。行高 29px，真实输入框 44px，搜索触发器 36px。
统一的视图外壳为 `max-width: 80rem`，每个视图都沿用页眉的精确水平内缩。

**背景。** 扁平的暖纸——默认无渐变、无网格、无玻璃、无颗粒纹理、无满幅 hero 摄影。
纵深来自**暖卡片色阶**（`--bg-app` → `--bg-card` → `--bg-4`），是一次色调梯级，
而非阴影或模糊。遮罩层是一道扁平的墨色罩
（`--scrim`，墨 25%），绝不用 `backdrop-blur`。

**边框——双重体系。** 所有边框都是 **1px**，绝不更粗。一道几乎不可见的**细描边**
（`--hairline`）用于分隔线、表格行、标签页、输入框与幽灵边缘；以及**墨线描边**
（`--rule-ink`，纯墨——那处标志）用于带框、强调与选中的卡片以及主 CTA 边缘。
不用带色的侧边条边框。不用嵌套圆角。

**圆角半径——三档。** `0px` 结构性（导航、标签页、标题、大面板）· `4px` 主导
（卡片、输入框、侧栏项、徽标；行内代码 2px；搜索与图标触发器 8px；提示框 callout 10px）·
**全胶囊**（`9999px`：每个按钮、版本标签、开关、状态圆点、头像）。每个区块只用一种半径。

**卡片。** 两个家族。**柔角**：`--bg-card`/`--bg-1`，4px，可选细描边，无阴影，扁平。
**硬描边**：纸背景加 1px `--rule-ink`，0–4px，用于强调、带框或选中。绝不把卡片嵌进卡片
（见下文“布局”）。

**层级（Elevation）。** 本质上扁平。默认卡片与按钮的 `box-shadow: none`。唯一的阴影是
一道几乎不可见的哑光光晕（`--shadow-flyout`，零偏移，浅色下约 2% 黑 / 深色下一道柔和暗晕），
用于浮层与弹出框。不用 Material 层级，不用辉光，不用带偏移的投影。

**动效。** 近乎为零，只有两档。**即时**（0s）用于所有界面外框状态——按钮、导航、卡片、行。
**色变**（≤200ms ease，仅颜色与不透明度）用于内容级的淡入淡出、输入框与展开。
**状态反馈是颜色，绝不是几何**——悬停、激活与选中切换一个令牌（一次背景色阶梯级、文本颜色或一道环），
绝不在交互元素上用 `transform`、`scale`、`translate` 或 `box-shadow`。
不抬升、不弹跳、不脉动或旋转，不用自动轮播。
`prefers-reduced-motion` 由 [`tokens/base.css`](../../tokens/base.css) 中内置的全局守卫尊重。

**悬停、按下、焦点、选中**（仅颜色）：
- *悬停*——背景下沉一个色阶梯级；链接式文本淡至约 75% 强调色（按钮不在悬停时显示下划线）。
- *按下*——还原或回退一个梯级。不缩放。
- *Focus-visible*——通用焦点环：1.5px 强调色描边，`outline-offset: 2px`
  （或在行上用内嵌的强调色环）。仅键盘触发；鼠标绝不显示它。这是橙色唯一触及界面外框状态之处。
- *选中/激活*——导航：橙色文本加一道 0.5px 强调色下划线笔触（不是胶囊）。行：`--bg-2`
  色调加内嵌强调色环（绝不用逐行边框）。卡片：硬朗的 `--rule-ink` 描边。
  开关：实色墨文本（可选 ✓），不用厚重填充。

**透明度与模糊。** 几乎从不使用。淡淡的状态色调（约 12%）与墨色遮罩（约 25%）是日常使用中
仅有的透明度。**`backdrop-blur`、磨砂玻璃与 `bg-*/50` 玻璃**默认**被禁用**。

**布局——反盒式体系。** 头号失败模式是盒中盒。用能奏效的最廉价分隔来分组，每次只升一级：
留白 → 小节标题与对齐 → 细描边 `divide-y` → 背景色调梯级 → 一道细描边边框 →
墨线描边（最后手段）。每个逻辑区块至多**一个带边框的容器**；绝不把卡片嵌进卡片；
表格数据用 `divide-y`，绝不用逐行盒子；数据小块靠网格间距分组，而非六个带框卡片。
最大嵌套深度：2。统一的视图外壳；靠列跨度重排，绝不靠重新盒装。

## 图标

jojo 的界面外框是**轻图标的**——它倚靠字体、橙色强调色与卡片色阶，而非装饰性图标。
图标出现时一律**单线条（monoline）**：细的、均匀笔画的几何线性图标
（无填充、无双色调、无圆润卡通风格），按文本尺寸缩放并继承 `currentColor`，
从而读作墨色，或在激活控件上读作强调色。

- **图标集：** 经 CDN（`lucide@latest`）引入的 **[Lucide](https://lucide.dev)**。
  它干净的约 1.75px 单线条笔画正是 jojo 的 UI kit 与组件通用的制图美学。
- **如何使用：** `<i data-lucide="search"></i>` 然后 `lucide.createIcons()`，
  或内联 SVG。笔画继承 `currentColor`；绝不用状态色或图表色把图标当作界面外框来上色。
  默认尺寸：密集 UI 中 16–18px，营销中 20–24px。
- **状态是圆点或色调，而非图标。** 状态令牌（`--ok` / `--warning` / `--info` /
  `--danger`）中的小实心圆，或淡令牌色调的徽标样式。绝不用表情符号作状态。
- **不用表情符号**于产品或营销界面。不用 unicode 装饰符作为 UI 图标。系统唯一倚靠的字形是
  强调色（三级）CTA 上的尾箭头 `→`，以及用于选中筛选或开关的对勾 `✓`。
- **Logo：** `assets/logo/` 中 jojo 的小写 “j” 字母组合标志——一个 mark 加一个文字标，
  文字标用 display 怪诞体写出 “jojo”。两者都继承 `currentColor`；内联它们，
  以便在纸上呈墨色、在墨上呈米白。见
  [`assets/README.md`](../../assets/README.md)。

## 字体

jojo 的三个字族都是开源的，经
[`tokens/fonts.css`](../../tokens/fonts.css) 从 Google Fonts 加载：

- **Geist**——怪诞体无衬线，用于所有 UI 与标题，包括大号轻量的 display。
- **Geist Mono**——等宽体，用于所有代码、命令与搜索输入框、安装码片与版本号。
- **EB Garamond**——衬线体，用于真正的长篇引导段落与引文。

每个字族在 `tokens/typography.css` 的字体栈中都列在首位，系统回退字体排在其后。
绝不在单个控件内混用字族。
